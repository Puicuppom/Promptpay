# พร้อมเพย์ — QR รับเงิน

เว็บแอปสร้าง QR พร้อมเพย์มาตรฐาน EMV สำหรับรับเงิน ติดตั้งบนหน้าจอมือถือได้

## ฟีเจอร์

- เพิ่มได้หลายบัญชี สลับด้วยแถบด้านบน
- พร้อมเพย์จาก **เบอร์โทรศัพท์** หรือ **บัตรประชาชน** (ใส่ยอดเงินได้)
- **QR ธนาคาร** แบบคงที่: อัปโหลดรูป QR จากแอปธนาคาร แอปอ่านแล้ววาดใหม่ในกรอบ
- ใส่โลโก้ธนาคารเองได้ (อัปโหลดรูปจากเครื่อง)
- ส่งรูป QR เข้า LINE หรือส่งเลขบัญชีเป็นข้อความทาง LINE
- จัดการบัญชีผ่านปุ่ม ⚙️: ตั้งบัญชีเริ่มต้น (☆), สลับลำดับ (▲▼)
- กรอบสลิปทำเอง: โหลด Layout `layout/qr-pui-layout-1080x1920.png` → ออกแบบใน Canva (Instagram Story 1080×1920) → นำเข้ากรอบในแอป
- ซิงก์ขึ้น Supabase (ใช้บัญชีเดียวกับ PuiHome&Tax) — รัน `supabase/qr_pui.sql` ครั้งแรกครั้งเดียว
- ใส่จำนวนเงินได้ (ไม่บังคับ)
- บันทึกและแชร์ QR พร้อมแถบ Thai QR Payment
